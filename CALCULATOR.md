# Калькулятор переезда

Калькулятор находится на главной странице в разделе `#rechner`. Ссылка есть в меню и на первом экране. Работает на немецком, английском и русском без внешнего сервиса маршрутов. Расстояние по дороге клиент вводит вручную.

Это предварительная оценка по текущим почасовым ставкам сайта. Полный тариф пока не утверждён. Коэффициенты объёма, времени и вместимости — рабочие допущения, которые нужно откалибровать по выполненным заказам.

## Где менять расчёт

В `calculator.py`:

| Настройка | Текущее значение |
| --- | --- |
| `HOURLY_RATES['one']` | 60 €/час, водитель выполняет работу грузчика |
| `HOURLY_RATES['two']` | 80–100 €/час, два грузчика, один из них водитель |
| `HOURLY_RATES['driver']` | `None`: цена по запросу, ставка не придумана |
| `MODEL['van_volume_m3']` | 14 м³ за рейс, уточнить по автомобилю |
| `MODEL['average_speed_kmh']` | 50 км/ч для оценки времени в пути |
| `MODEL['occupancy']` | 0,22 / 0,32 / 0,45 м³ на м² |
| `MODEL['inventory_price_multiplier']` | 1,25: +25% к обеим границам цены только в режиме списка вещей |
| `ITEMS` | Типовые предметы и примерный объём каждого |

Оценка по квартире использует большую из двух площадей: введённую площадь и количество комнат × 15 м². При выборе списка вещей объём берётся только из списка, без добавления объёма квартиры.

В режиме «По списку вещей» обе рассчитанные границы стоимости умножаются на 1,25. Например, 300–450 € превращаются в 375–562,50 €. Суммы сохраняются до центов; длительность, объём и число рейсов от этой надбавки не меняются. В режиме расчёта по квартире надбавки нет, даже если ранее клиент заполнял список. Вариант только с водителем остаётся «по запросу».

Число рейсов = объём / 14 м³ с округлением вверх. Расстояние между точками включает обратные поездки за следующей загрузкой: расстояние А–Б × (2 × количество рейсов − 1). Это модель одного автомобиля, не гарантия перевозки по объёму или грузоподъёмности.

Рабочее время складывается из переноса на обоих адресах, погрузки/разгрузки, времени поездок и подготовки. Этажи, возможность пользоваться лифтом и путь до машины меняют время работ, а не отдельную фиксированную доплату. Для двух грузчиков учитывается более высокая производительность.

Из полученного времени формируется диапазон с округлением до получаса. Нижняя граница цены использует нижнюю ставку, верхняя — верхнюю. Это оценка длительности, не установленный минимальный заказ. Налог отдельно не добавляется: используются ровно суммы, указанные на сайте. До публикации полного тарифа нужно уточнить условия этих ставок и состав окончательной цены.

Выезд с базы, возврат на базу, парковочные сборы, упаковка и монтаж не включены. Для варианта «30 м и более» модель использует 30 м; большие расстояния и особые предметы требуют ручного уточнения. Эти ограничения указаны клиенту в результате.

## Заявка и безопасность

`POST /calculate` проверяет входные данные и считает результат на сервере. Работают CSRF и ограничение запросов. В браузере нет авторитетных цен или коэффициентов.

Кнопка под результатом прикладывает параметры к существующей форме контакта. Сам расчёт писем не отправляет. При отправке заявки сервер повторно проверяет параметры, пересчитывает сумму и добавляет немецкую сводку в письмо. Сообщение клиента сохраняется. Изменение параметров калькулятора снимает прежнее вложение, чтобы не отправить устаревшие данные.

SMTP-переменные и способ отправки остались прежними. База данных и новые зависимости не нужны.

## Проверка

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты используют подмену SMTP и не отправляют реальные письма. Для ручной проверки запустить `app.py`, открыть `http://127.0.0.1:5000/#rechner` и пройти все три шага. Отправка обычной контактной формы при рабочих SMTP-настройках отправляет настоящее письмо.
